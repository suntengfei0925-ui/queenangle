# 需求 03：飞书进货台账入口

## 基本信息
- 版本：03
- 需求简称：飞书进货台账入口
- 适用系统：QueenAngle 网页端
- 适用设备：手机优先
- 使用角色：所有已登录用户
- 当前状态：已澄清，待开发

## 1. 背景
门店进货台账、合格证、票据、供应商资料等内容已决定放在飞书多维表格中维护。QueenAngle 不承载这些台账数据，只作为门店日常系统入口，方便用户从设置页快速跳转到飞书。

该需求的核心是增加稳定入口，而不是把飞书数据同步到 QueenAngle。

## 2. 目标
- 在 QueenAngle 设置页增加两个飞书外部链接入口。
- 用户可点击查看进货台账。
- 用户可点击填写新的进货记录。
- 第一版不做权限区分，所有登录用户可见。
- 第一版不做飞书数据同步、不做附件上传、不做表单内嵌。
- 外部链接使用配置文件维护，便于未来继续增加类似入口。

## 3. 使用角色与可见性
- 所有已登录用户都可以看到入口。
- 暂时不区分老板和店员权限。
- 未登录用户不能进入设置页，因此不能看到入口。
- 飞书文档和表单的访问权限由飞书自身控制。

## 4. 使用流程
1. 用户登录 QueenAngle。
2. 用户点击底部“设置”。
3. 用户在“次卡类型”下方看到一条细线。
4. 细线下方依次看到两个入口：
   - 进货台账
   - 新增进货记录
5. 用户点击“进货台账”，跳转到飞书台账页面。
6. 用户点击“新增进货记录”，跳转到飞书表单页面。
7. 用户在飞书 App 内完成查看或填写。

## 5. 页面需求
- 入口位置：设置页“次卡类型”下方。
- “次卡类型”和飞书入口之间只增加一条细线。
- 不增加分组标题。
- 不增加说明文字。
- 细线下方依次展示：
  1. `进货台账`
  2. `新增进货记录`
- 不改变设置页其他入口的原有功能。
- 不改变退出登录入口的原有逻辑。

## 6. 链接配置
第一版应使用静态配置文件维护设置页外部链接，不建议直接把链接写死在页面结构中。

推荐配置结构：

```json
{
  "settingsExternalLinks": {
    "dividerBefore": true,
    "items": [
      {
        "id": "purchase-ledger",
        "name": "进货台账",
        "url": "https://mcn44hy96wn8.feishu.cn/wiki/Jbgzw5cntigw36kkyh0cUOrVnng?table=tbl3W947Dzap2tgy&view=vew4Pni2OJ",
        "enabled": true,
        "order": 10
      },
      {
        "id": "purchase-form",
        "name": "新增进货记录",
        "url": "https://mcn44hy96wn8.feishu.cn/wiki/Jbgzw5cntigw36kkyh0cUOrVnng?table=tbl3W947Dzap2tgy&view=vewpBQIuBr",
        "enabled": true,
        "order": 20
      }
    ]
  }
}
```

字段说明：
- `settingsExternalLinks`：设置页外部链接配置。
- `dividerBefore`：是否在外部链接前显示分割线。
- `items`：外部链接列表。
- `id`：稳定标识，后续改名称或链接时不影响代码识别。
- `name`：设置页展示名称。
- `url`：跳转链接。
- `enabled`：是否启用该入口。
- `order`：排序值，便于未来插入更多入口。

## 7. 业务规则
- 点击入口后打开对应飞书链接。
- 默认用户设备已安装飞书 App，不额外设计浏览器兜底体验。
- QueenAngle 不校验飞书权限。
- QueenAngle 不保存飞书表单数据。
- QueenAngle 不读取飞书表格内容。
- QueenAngle 不在本系统内上传或保存台账图片。
- 若未来入口变多，优先通过配置文件增加，不改页面结构。

## 8. 异常情况
- 飞书未登录：由飞书处理登录。
- 飞书无权限：由飞书提示无权限。
- 飞书链接失效：QueenAngle 不做额外补救。
- 网络异常：由系统或飞书显示网络错误。
- 配置项 `enabled = false` 时，不展示该入口。
- 配置项缺少 `name` 或 `url` 时，不应渲染为可点击入口。

## 9. 权限与隐私
- 第一版不区分老板和店员，所有登录用户可见。
- 飞书台账中的票据、供应商、订单截图、电话等资料由飞书权限控制。
- QueenAngle 只展示入口名称，不展示台账内容。
- 不在 QueenAngle 数据库中保存飞书链接访问记录。

## 10. 验收标准
- 设置页“次卡类型”下方出现一条细线。
- 细线下方依次显示“进货台账”“新增进货记录”。
- 不显示分组标题。
- 不显示说明文字。
- 点击“进货台账”能打开指定飞书表格链接。
- 点击“新增进货记录”能打开指定飞书表单链接。
- 所有登录用户都能看到这两个入口。
- 设置页现有入口和退出登录功能不受影响。
- 修改配置中的链接后，页面跳转目标随配置变化。
- 将某个配置项设为 `enabled = false` 后，该入口不展示。

## 11. 开发交接版

### 影响范围
- 页面：`web/index.html`、`web/app.js`、`web/styles.css`
- 配置：新增前端静态配置文件，用于维护设置页外部链接
- 后端/API：第一版不需要
- 数据库：第一版不需要
- 权限：第一版不需要

### 建议拆分
- 第 1 步：新增设置页外部链接配置文件。
- 第 2 步：设置页读取配置并按 `order` 渲染启用入口。
- 第 3 步：在“次卡类型”下方增加细线和外链入口区域。
- 第 4 步：验证两个链接跳转、禁用配置、移动端显示。

### 测试场景
- 正常流程：登录后进入设置页，点击两个入口，分别打开正确飞书链接。
- 配置禁用：将其中一个入口 `enabled` 改为 `false`，页面不展示该入口。
- 配置排序：调整 `order` 后，页面顺序按配置变化。
- 异常配置：缺少 `url` 的配置项不应展示为可点击入口。
- 回归验证：服务分类、服务项目、充值档位、次卡类型、退出登录仍可正常使用。
