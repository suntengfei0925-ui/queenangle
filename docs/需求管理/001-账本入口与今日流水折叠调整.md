# 账本入口与今日流水折叠调整 PRD

## 1. 背景

当前小程序首页默认展示“今日流水”，包括今日实收、有效笔数、消费金额、余额支付、充值等经营数据。实际使用场景中，老板经常会在客户旁边操作小程序，例如结账、查订单、确认客户消费记录。客户看到自己的订单信息没有问题，但首页直接暴露店铺当天流水不合适。

因此需要调整首页入口，把首屏改成“记一笔”，并将经营流水信息移动到最后一个 Tab“账本”。

## 2. 目标

本次需求解决以下问题：

- 打开小程序后默认进入“记一笔”，方便老板快速记账。
- 今日流水不再出现在首页，降低客户旁观时看到经营数据的概率。
- 在账本页中将“今日流水”默认折叠，老板需要时点击展开即可查看。

本次不做：

- 日期筛选
- 历史账本查询
- 权限密码
- 流水计算规则调整
- 订单字段调整

## 3. 使用角色与可见性

主要操作者是老板或店内被授权人员。客户可能在结账、查订单、看会员订单时看到屏幕。

客户可以看到订单列表、自己的订单金额、支付方式、服务项目、记录状态等信息。需要弱隐藏的是“今日流水汇总区”，它默认折叠，不在页面打开时直接展示金额和统计数据。

## 4. 页面结构

底部 Tab 调整为：

```text
记一笔 / 会员 / 设置 / 账本
```

第一个 Tab“记一笔”承接当前 `记一笔` 页内容，包含以下业务入口：

- 散客消费
- 会员充值
- 会员消费
- 次卡购买
- 次卡核销

最后一个 Tab 为“账本”，承接当前首页中的“今日流水”和“今日记录”。

## 5. 账本页需求

账本页顶部展示“今日流水”折叠入口。默认状态为折叠，只保留较小高度的入口区域，展示标题、日期和“展开”按钮，不展示任何金额、笔数、支付构成等业务数据。

点击“展开”后，展示完整今日流水内容，包括当前已有的今日实收、有效笔数、消费金额、余额支付、充值等汇总。展开后按钮变为“折叠”，点击后恢复默认折叠状态。

账本页下方展示“今日记录”列表，默认直接展示。每条记录继续保留当前信息，包括业务类型、状态、名称信息、实收金额、支付方式，并可进入记录详情。

账本页不需要保留“刷新”按钮。数据刷新由页面进入或 Tab 切回触发：每次进入“账本”页，或从其他 Tab 切回“账本”页时，自动重新拉取当日流水和今日记录。若用户怀疑数据不是最新，可切换到第一个 Tab“记一笔”后再切回“账本”，以触发刷新。

## 6. 业务规则

今日流水计算规则保持不变：只统计当天 `active` 状态记录。作废记录不计入流水汇总，但仍可按当前记录列表规则展示状态。

记一笔、会员、设置、订单详情、会员详情等业务功能不改变。日期筛选未来会加入账本页，但不纳入本次范围。

## 7. 数据需求

本次不新增数据字段，不改变 `records` 数据结构，不改变流水相关计算字段。折叠状态默认折叠即可，不要求跨会话记忆。

如果开发时需要页面内状态，只作为前端临时 UI 状态处理，不影响数据库。

## 8. 异常情况

账本页无今日记录时，继续展示当前空状态。今日流水折叠状态下，即使无数据也应显示入口和展开按钮。接口加载失败时，沿用当前错误提示方式。

从其他页面返回账本页时，今日流水应保持默认折叠，避免重新进入时直接暴露流水。

## 9. 权限与隐私

本次不新增密码、二次确认或角色权限。隐私保护方式是“默认不展开 + 需要主动点击展开”。订单级信息不需要隐藏。

## 10. 验收标准

1. 打开小程序默认进入第一个 Tab“记一笔”，页面内容为当前五个记账入口。
2. 底部 Tab 顺序为 `记一笔 / 会员 / 设置 / 账本`，账本位于最后。
3. 首页不再展示今日流水。
4. 进入“账本”页时，今日流水默认折叠，不显示金额、笔数或支付统计。
5. 点击“展开”后展示完整今日流水，按钮变为“折叠”。
6. 点击“折叠”后隐藏完整流水内容，只保留小入口。
7. 今日记录列表在账本页正常展示，记录金额和支付方式保持现状。
8. 流水统计结果与调整前一致，只是展示位置和默认状态改变。
9. 账本页不展示“刷新”按钮。
10. 每次进入“账本”页或从其他 Tab 切回“账本”页时，自动刷新当日流水和今日记录。

## 11. 待确认问题

无本次开发阻塞问题。“账本”名称为暂定名，如后续需要可再改为“流水”或“经营”。

## 开发交接版

### 影响范围

- 页面：当前 `pages/home/index`、`pages/entry/index`
- 底部导航：`app.json` tabBar 顺序和名称
- 账本数据：沿用当前首页 `getHomeSummary` 数据
- 云函数/API：原则上不改计算规则
- 数据库：不新增字段，不迁移历史数据
- 权限隐私：不新增权限，只做前端默认折叠

### 建议拆分

- 第 1 步：调整 Tab 结构，让第一个 Tab 成为“记一笔”，最后一个 Tab 为“账本”。
- 第 2 步：将当前首页的今日流水和今日记录迁移到账本页。
- 第 3 步：为今日流水增加默认折叠/展开状态，折叠时隐藏整块汇总内容。
- 第 4 步：移除账本页手动刷新按钮，确保进入或切回账本页时自动刷新数据。
- 第 5 步：回归测试记账入口、今日记录、记录详情、作废状态和流水统计一致性。

### 测试场景

- 正常流程：打开小程序，默认看到“记一笔”入口。
- 隐私流程：进入“账本”，今日流水默认折叠，不露出金额。
- 展开流程：点击展开后完整显示流水，再点击折叠后隐藏。
- 刷新流程：账本页不出现刷新按钮；从“记一笔”切回“账本”后，自动重新加载今日流水和今日记录。
- 数据回归：新增一笔消费后，账本页今日记录出现，展开流水后统计金额正确。
- 作废回归：作废记录不计入今日流水汇总，记录状态仍正确显示。
