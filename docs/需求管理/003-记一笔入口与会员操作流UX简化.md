# 记一笔入口与会员操作流 UX 简化 PRD

## 1. 背景

当前“记一笔”页面一次性展示散客消费、会员充值、会员消费、次卡购买、次卡核销，入口过多。真实业务里，散客只需要直接结账；会员业务应先确定会员是谁，再围绕该会员进行消费、充值、编辑等操作。

当前流程中，老板进入会员消费或会员充值页面后还要再选择会员，流程顺序不符合真实场景。更合理的流程是：先确认站在面前的会员是谁，再围绕该会员办理消费、充值等业务。

## 2. 目标

本次只调整 UI/UX 和页面流转，不调整消费、充值、折扣、次卡等业务计算逻辑。

目标是将底部导航和记账入口简化为：

```text
记一笔 / 账本 / 设置
```

“会员管理”不再作为底部 Tab 展示；相关代码可以保留，但本次不提供独立入口。

## 3. 使用角色与可见性

主要操作者是老板或店内人员。客户可能在结账时看到屏幕。本次不新增隐私隐藏规则，重点是降低入口复杂度和减少误操作。

## 4. 使用流程

### 4.1 记一笔首页

“记一笔”页面只保留两个大入口：

- 会员：视觉权重更高，位于上方。
- 散客结账：位于下方，点击后直接进入现有散客消费页面。

比例不要求严格 6:4，只体现会员入口更重要。

### 4.2 选择会员页

点击“会员”后进入“选择会员”页。该页面替代原来的会员管理列表能力：

- 默认展示全部会员。
- 支持按姓名、手机号、手机号后四位实时模糊搜索。
- 不使用系统 picker。
- 底部固定较小的“新建会员”按钮。
- 点击会员后直接进入“会员操作台”。
- 新建会员完成后，直接进入该会员的“会员操作台”。

### 4.3 会员操作台

页面标题使用“会员详情”，不直接把客户姓名放在顶部导航标题。

页面上方展示会员摘要：

- 姓名
- 手机号
- 当前余额
- 当前折扣
- 次卡明细

页面主体保留两个主要入口：

- 消费结账：进入会员消费页面，会员已自动选好。
- 充值：进入会员充值页面，会员已自动选好。

编辑会员作为弱入口处理，例如右上角小 icon 或小按钮，不做成大入口。

## 5. 页面规则

进入会员消费或会员充值页面后：

- 页面顶部显示已选会员摘要。
- 原来的会员选择控件移除或隐藏。
- 不允许在页面内更换会员。
- 如果选错会员，需要返回选择会员流程重新选择。
- 提交成功后返回会员操作台。

散客结账页面保持现有逻辑、字段和提交流程不变。

## 6. 本次不做

- 不调整散客结账页面细节。
- 不调整会员消费页面的具体结账规则。
- 不调整会员充值页面的具体充值规则。
- 不重新设计次卡购买和次卡核销。
- 不新增会员管理独立入口。
- 不修改业务计算逻辑。

次卡购买和次卡核销后续会分别并入充值/消费体验中，另起需求设计。

## 7. 验收标准

1. 底部 Tab 只显示 `记一笔 / 账本 / 设置`。
2. “记一笔”首页只显示“会员”和“散客结账”两个入口。
3. 点击“散客结账”直接进入现有散客消费页面。
4. 点击“会员”进入选择会员页，默认展示全部会员。
5. 选择会员页支持姓名、手机号、手机号后四位实时搜索。
6. 点击会员后直接进入会员操作台。
7. 新建会员成功后直接进入该会员操作台。
8. 会员操作台标题为“会员详情”，页面内展示会员摘要。
9. 会员操作台只突出“消费结账”和“充值”两个主入口。
10. 编辑会员入口存在，但弱化展示。
11. 会员消费/充值页面自动带入会员，且不能在页面内更换会员。
12. 会员消费/充值提交成功后返回会员操作台。

## 开发交接版

### 影响范围

- 底部导航：移除会员 Tab，顺序调整为 `记一笔 / 账本 / 设置`。
- 页面：改造 `记一笔` 首页入口。
- 页面：新增或改造“选择会员”页。
- 页面：新增或改造“会员操作台”页。
- 页面：会员消费、会员充值支持从已选会员进入并隐藏会员选择控件。
- 保留但不展示：原会员管理页代码可保留，暂不提供入口。

### 建议拆分

- 第 1 步：调整底部 Tab。
- 第 2 步：简化“记一笔”首页为会员/散客两个入口。
- 第 3 步：实现选择会员页，支持实时搜索和新建会员后直达操作台。
- 第 4 步：实现会员操作台，展示摘要、消费、充值、编辑弱入口。
- 第 5 步：改造会员消费/充值入口，使页面自动带入会员且不可切换。
- 第 6 步：回归测试散客结账、会员消费、会员充值、新建会员、编辑会员。

### 测试场景

- 打开小程序，底部只看到 3 个 Tab。
- 从“记一笔”点散客结账，能进入原散客消费页面。
- 从“记一笔”点会员，能搜索并选择会员。
- 新建会员成功后，直接进入该会员操作台。
- 在会员操作台点消费结账，会员消费页面已带入该会员。
- 在会员操作台点充值，会员充值页面已带入该会员。
- 会员消费/充值提交后返回会员操作台。
- 原会员 Tab 不再展示。
