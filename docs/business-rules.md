# 业务规则落地

## 会员充值

- 选择充值档位。
- 会员余额增加档位金额。
- 会员当前折扣更新为本次档位折扣。
- 生成充值记录和余额流水。

## 会员消费

消费必须选择至少一个服务项目。每个项目保存分类、项目名称和单项原价快照，整单原价为所有单项原价之和。

余额大于 0 且存在当前折扣时：

```text
消费金额 = 整单原价 * 折扣 / 10
余额支付 = min(当前余额, 消费金额)
补差价 = 消费金额 - 余额支付
```

余额为 0 时：

```text
消费金额 = 整单原价
余额支付 = 0
补差价 = 整单原价
```

余额扣到 0 后：

```text
currentDiscount = null
currentDiscountLabel = 无折扣
```

## 散客消费

- 不绑定会员。
- 不影响余额和次卡。
- 必须选择至少一个服务项目，每个项目单独填写原价。
- 整单原价为所有服务项目单项原价之和。
- 实收金额等于本次新收款。

## 服务分类与服务项目

- 服务分类可新增、编辑、启用或停用。
- 新增服务分类时，自动创建一个启用状态的“其他”服务项目。
- 服务项目归属于服务分类，只维护名称、备注和启用状态，不维护固定价格。
- 同一分类下服务项目名称不允许重复，不同分类下允许重复。
- 结账选择服务项目时，同分类下项目按有效消费次数倒序排列；“其他”始终排在该分类最后。

## 次卡购买

- 增加会员名下对应次卡剩余次数。
- 生成购买记录和次卡流水。

## 次卡核销

- 默认核销 1 次。
- 不允许核销超过剩余次数。
- 不产生消费金额和实收金额。

## 作废

- 记录不硬删除，只把状态改为 `void`。
- 今日流水统计只计算 `active` 记录。
- 有会员状态变更的记录会按 `memberBefore` 快照回滚。
