# 业务规则落地

## 会员充值

- 选择充值档位。
- 会员余额增加档位金额。
- 会员当前折扣更新为本次档位折扣。
- 生成充值记录和余额流水。

## 会员消费

余额大于 0 且存在当前折扣时：

```text
消费金额 = 原价 * 折扣 / 10
余额支付 = min(当前余额, 消费金额)
补差价 = 消费金额 - 余额支付
```

余额为 0 时：

```text
消费金额 = 原价
余额支付 = 0
补差价 = 原价
```

余额扣到 0 后：

```text
currentDiscount = null
currentDiscountLabel = 无折扣
```

## 散客消费

- 不绑定会员。
- 不影响余额和次卡。
- 实收金额等于本次新收款。

## 次卡购买

- 增加会员名下对应次卡剩余次数。
- 生成购买记录和次卡流水。

## 次卡核销

- 默认核销 1 次。
- 不允许核销超过剩余次数。
- 不产生消费金额和实收金额。

## 作废

- 记录不硬删除，只把状态改为 `void`。
- 今日流水统计只计算 `active` 记录。
- 有会员状态变更的记录会按 `memberBefore` 快照回滚。
